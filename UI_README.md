# AI Text Detection UI

A simple Streamlit-based interface for viewing model statistics and classifying text as AI-generated or human-written.

## Features

- **Model Statistics**: View performance metrics and feature importance for all trained models
- **Text Classification**: Test your own text with multiple models simultaneously
- **Model Comparison**: Compare predictions from Baseline, BERT, and RoBERTa models side-by-side

## Prerequisites

Make sure you have trained at least one model before using the UI. The app looks for:
- `models/baseline_model.pkl` - Baseline logistic regression model
- `models/bert_model.pt` - Fine-tuned BERT model
- `models/roberta_model.pt` - Fine-tuned RoBERTa model
- `models/feature_importance.csv` - Feature importance data from baseline model
- `results/*.csv` - Model evaluation metrics

## Installation

1. Install required dependencies:
```bash
pip install streamlit
```

Or install all project dependencies:
```bash
pip install -r requirements.txt
```

## Running the UI

From the project root directory, run:

```bash
streamlit run app.py
```

The app will open in your default web browser at `http://localhost:8501`

## Using the UI

### Model Statistics Page
- View performance metrics for all trained models
- See feature importance for the baseline model (top 15 features)
- Check which models are currently loaded and available

### Text Classification Page
1. Enter or paste text in the text area
2. Select which models you want to use for classification
3. Click "Classify" to see predictions
4. View results showing:
   - Prediction (AI-Generated or Human-Written)
   - Confidence score
   - Probability distribution (Human vs AI)
5. Use the example buttons to load sample texts

## Model Predictions

- **Human-Written (0)**: Text appears to be written by a human
- **AI-Generated (1)**: Text appears to be generated by AI

Each model provides:
- A prediction (0 or 1)
- Confidence score (percentage)
- Probability for each class

## Troubleshooting

**Models not loading:**
- Make sure you've trained the models first
- Check that model files exist in the `models/` directory
- Verify file names match expected patterns

**Import errors:**
- Install missing dependencies: `pip install -r requirements.txt`

**Performance issues:**
- BERT and RoBERTa models require significant memory
- Close other applications if running on limited hardware
- Models will use GPU if available, CPU otherwise

## Notes

- The UI loads models on first access and caches them for performance
- BERT and RoBERTa models may take a few seconds to load initially
- Longer texts may take more time to process with transformer models
